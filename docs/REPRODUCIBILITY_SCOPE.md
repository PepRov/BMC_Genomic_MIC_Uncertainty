# Reproducibility scope and upstream boundary

## Included and immediately auditable

The package includes **11 reviewed intermediate datasets**, preserving the exact dataset names that the original notebooks refer to. The computation can proceed from the two NB40 outputs into NB41–43, and from those outputs into NB50–55 and figures 2–4. An independent `verify_package.py` script checks expected sizes, observation identity and main reported performance metrics. It is not a substitute for rerunning model fits.

Notebooks NB41, NB42, NB43 and NB55 can be computationally expensive. The files in `03_Results/` preserve results from the earlier analysis, allowing the downstream computations to be reproduced without unnecessarily refitting all previous stages.

## Upstream Model C computations not distributed

- NB39 requires `26_nested_pathogen_out_predictions.csv.gz` and `26_model_c_aligned_interactions.csv.gz`, from the earlier Model C analysis.
- NB40 reconstructs the original Model C inner predictions from archives `26_model_c_nested_pathogen_out_and_reference_model_outputs.zip`, `25_model_c_pathogen_kernel_candidate_components.zip`, and `16B_optimised_full_gene_model3_interaction_outputs.zip`. Selected embedding checkpoints can also be used to avoid expensive spectral reconstruction. These archives/checkpoints are **not** in this repository.
- NB47 can regenerate the supplied group assignments only with the earlier aligned interaction index and original genomic embeddings `26_locus_rho_0p3_embedding.npz` and `26_locus_rho_0p4_embedding.npz`. These are **not** in this repository. The notebook uses training-only genomic groups and does not use held-out MIC outcomes to construct them.
- NB50 requires only the saved NB47 group assignments, so its descriptive group uncertainty analysis **does** run with packaged files.

As a result, this package supports the BMC analysis **conditional on the supplied validated Model C predictions and genomic assignments**, rather than a full end-to-end reconstruction from raw genomes.

## Notes for independent reuse

1. Original notebook files were restored from valid notebook JSON text available in the author's Library. The code cells and ordering are not altered. The original notebook binary exports were not available as direct container downloads, so byte-for-byte identity with an earlier local notebook file is not claimed.
2. The notebooks have their original output directories and may overwrite results if rerun. Copy the package if you wish to preserve the released data unchanged.
3. `Figure04_BMCN_Probability_Calibration_v0.5.ipynb` includes only the verified 60-row aggregated reliability-bin table inside Cell 2, avoiding exposure of individual BioSample identifiers or observations in the figure notebook. It is self-contained and will save results to `Figure04_outputs/` beneath the *current Jupyter working directory*.
4. Figure 1 is an explanatory workflow diagram rather than a statistical plot and is supplied in the manuscript, not generated by a notebook.
5. Fold-specific genomic group numbers are **not aligned labels across folds**. Each fold independently fits four groups.
6. Some breakpoint values are indication-restricted; clinical indication and specimen are unavailable in the underlying prediction data.
